Importar e exportar dados

Importe arquivos CSV com cabeçalhos. O arquivo JSON exportado contém todos os registros e pode ser usado como cópia de segurança.

Conectores externos

Esta versão funciona localmente no navegador. Para integrar sistemas, serviços meteorológicos ou bancos de dados, é necessário configurar um servidor/API, autenticação e regras de acesso.

Privacidade e armazenamento

Os registros ficam salvos no armazenamento local deste navegador. Eles não são enviados automaticamente a terceiros. Limpar os dados do navegador pode apagar os registros; faça backups periódicos.
