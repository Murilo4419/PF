6. Como funciona o cálculo e quais são as limitações?

Tendência composta: a cada mês, o valor-base é multiplicado por (1 + taxa mensal). Isso representa crescimento percentual composto, não soma fixa.

Clima e mercado: os impactos informados são tratados como efeitos totais ao fim do horizonte e distribuídos gradualmente. O fator combinado no mês t é (1 + clima) × (1 + mercado), elevado à fração t/horizonte. Assim, o impacto não é reaplicado integralmente todos os meses.

Cenários: pessimista e otimista aplicam uma margem que cresce proporcionalmente ao longo do horizonte. No último mês, a margem alcança o percentual configurado.

Importação: o CSV aceita cabeçalho periodo,valor. A API deve responder com uma lista JSON de objetos com periodo e valor. Para APIs em outro domínio, o servidor precisa permitir CORS.

Limitações: o modelo é determinístico e simplificado. Não estima sazonalidade, intervalos de confiança, correlação entre clima e preço, nem choques inesperados. A taxa histórica automática é uma taxa composta média entre o primeiro e o último registro e pressupõe intervalos mensais regulares.

Privacidade: o histórico fica no navegador durante a sessão; este arquivo não envia dados para um servidor. A conexão com API só ocorre quando você aciona o botão correspondente.

Módulo demonstrativo. Valide a qualidade, a periodicidade e a unidade dos dados antes de utilizar as estimativas em decisões financeiras, comerciais ou operacionais.
